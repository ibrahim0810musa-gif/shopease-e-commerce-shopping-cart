# ShopEase — E-Commerce Shopping Cart

ShopEase is a frontend e-commerce shopping cart website built with HTML, CSS, and JavaScript. It allows users to browse products, search and filter items, manage their shopping cart, and review their order through a checkout form.

This project is part of my journey to becoming a professional frontend developer.

## Features

* Browse products in a clean shopping interface
* Search for products by name
* Filter products by category
* Add products to the shopping cart
* Manage cart items and quantities
* Calculate the shopping cart total
* Save cart data using browser localStorage
* Clear the cart with a confirmation popup
* Review an order in the checkout panel
* Enter customer and delivery information
* Responsive styling for different screen sizes

## Technologies Used

* HTML5 — website structure
* CSS3 — layout, styling, and responsive design
* JavaScript — product rendering, cart logic, DOM manipulation, and interactivity
* localStorage — saving cart data in the browser

## Project Files

* `index.html` — the main website structure
* `style.css` — website styling
* `script.js` — product, shopping cart, and checkout functionality

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional packages are required to run this frontend project.
